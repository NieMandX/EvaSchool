# EvaSchool · Контур

«Контур» — детская викторина по географии. [Играть на GitHub Pages](https://niemandx.github.io/EvaSchool/). Для игры без интернета откройте собранный файл `dist/index.html` в браузере. Карта, шрифт и код находятся в одном файле.

Раунд состоит из 10 заданий. За верный ответ засчитывается одна найденная страна, затем игра сама переходит к следующему заданию после короткой паузы. Ошибочный ответ можно исправить. При пропуске глобус показывает нужную страну и ждёт нажатия кнопки перехода. Следующие раунды берут задания из набора из 32 стран.

- Поворот — перетаскивание мышью или одним пальцем.
- Масштаб — колесо, щипок или кнопки **+** и **−**.
- С клавиатуры на глобусе работают стрелки, **+**, **−**, **Enter** для выбора страны в центре и **Home** для сброса вида. **Shift** со стрелкой поворачивает глобус меньшим шагом.

При перетаскивании глобус следует за указателем. Колесо и щипок удерживают выбранную точку в пределах доступной области сдвига. Новое касание сразу останавливает инерцию и прерывает анимацию масштаба. Пауза после верного ответа считается только пока вкладка видима.

## Сборка

Используйте Node.js 22.

```sh
npm ci
npm test
npm run build
npm run preview
```

Локальный адрес — `http://127.0.0.1:4387/`. Для запуска готового файла эти команды не требуются.

При каждом обновлении `main` GitHub Actions запускает тесты, собирает HTML и публикует его на GitHub Pages. В настройках Pages источником публикации выбран GitHub Actions.

## Данные карты

Контуры взяты из Natural Earth через [World Atlas 2.0.2](https://github.com/topojson/world-atlas). Группировка суши по материкам основана на [world-countries 5.1.0](https://github.com/mledoze/countries). [Подготовленный файл карты](src/assets/countries.json) доступен под [ODbL 1.0](src/assets/World-Countries-ODbL.txt). Европа и Азия объединены в Евразию. На карте подписаны пять океанов. Лицензии также включены в собранный HTML.

Глобус рисуется на Canvas 2D. Вершины заранее переводятся в трёхмерные координаты, а длинные дуги один раз разбиваются на короткие отрезки. При вращении и масштабировании используются те же контуры. Берега читаются по краю заливки и тени на воде. Линиями отмечены общие границы стран. В покое карта не перерисовывается. Системная настройка уменьшения движения заменяет подъём страны цветовым откликом и отключает инерцию. Короткий тактильный отклик при переходе между странами и выборе доступен на устройствах с поддержкой Web Vibration API.

На устройствах с WebGPU мягкая тень вдоль берега рассчитывается на GPU. Контуры, подписи и взаимодействие используют один и тот же код во всех браузерах. Игра запускается на Canvas 2D и сохраняет этот режим, если WebGPU недоступен. При потере доступа к GPU возврат на Canvas 2D происходит автоматически. Для сравнения можно открыть `?renderer=canvas`. Сборка Canvas 2D рассчитана на Safari 15.4+, Chrome 105+ и Firefox 110+.
