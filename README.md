# EvaSchool · Контур

«Контур» — детская викторина по географии. [Играть на GitHub Pages](https://niemandx.github.io/EvaSchool/). Для игры без интернета откройте собранный файл `dist/index.html` в браузере. Карта, шрифт и код находятся в одном файле.

Раунд состоит из 10 заданий. Кружки вверху показывают ход раунда. За верный ответ засчитывается одна найденная страна, затем игра сама переходит к следующему заданию после короткой паузы. Ошибочный ответ можно исправить. Кнопка «Подсказка» открывает подсказку и возможность показать ответ на глобусе. Следующие раунды берут задания из набора из 32 стран.

Кнопка «Игрок» открывает профиль и рейтинг. Можно выбрать псевдоним или играть гостем. Игрок получает 1 балл за страну, найденную с первой попытки без подсказки. В личный рекорд идёт лучший результат раунда из 10 баллов. В одном браузере можно завести несколько профилей и переключаться между ними по имени.

- Поворот — перетаскивание мышью или одним пальцем.
- Масштаб — колесо или щипок.
- С клавиатуры на глобусе работают стрелки, **+**, **−**, **Enter** для выбора страны в центре и **Home** для сброса вида. **Shift** со стрелкой поворачивает глобус меньшим шагом.

При перетаскивании глобус следует за указателем. После отпускания он продолжает движение со скоростью конца жеста и плавно останавливается. Колесо и щипок удерживают выбранную точку в пределах доступной области сдвига. Новое касание сразу останавливает инерцию и прерывает анимацию масштаба. Пауза после верного ответа считается только пока вкладка видима.

## Сборка

Используйте Node.js 22.

```sh
npm ci
npm test
npm run build
npm run preview
```

Локальный адрес — `http://127.0.0.1:4387/`. Для запуска готового файла эти команды не требуются.

При каждом обновлении `main` GitHub Actions запускает тесты, собирает HTML и публикует его на GitHub Pages. В настройках Pages источником публикации выбран GitHub Actions.

### Общий рейтинг

Локальный предпросмотр использует ту же SQLite-базу в обычной и сервисной сборках. Путь к файлу задаёт `KONTUR_RANKINGS_DB`. По умолчанию используется `.kontur-ranking.sqlite`.

Для общего рейтинга с GitHub Pages запустите `npm run start:ranking` на сервере с Node.js 22 и постоянным диском. По умолчанию сервер слушает `127.0.0.1:4389`. Адрес и порт задают `KONTUR_RANKINGS_HOST` и `KONTUR_RANKINGS_PORT`. Настройте перед сервером HTTPS и задайте `KONTUR_RANKINGS_ORIGIN=https://niemandx.github.io`. В переменной репозитория `KONTUR_RANKINGS_URL` укажите HTTPS-адрес API с путём `/api/ranking`, затем соберите и опубликуйте сайт.

При подключённом API общий список показывает псевдонимы и рекорды. Для перехода в общий список игрок сохраняет имя в окне профиля. Без API рейтинг работает внутри текущего браузера. Профиль привязан к браузеру, в котором его создали.

## Сервисная сборка

```sh
npm run build:service
npm run preview:service
```

Откройте `http://127.0.0.1:4388/` или `dist-service/index.html` и нажмите **N**, чтобы открыть или закрыть панель. Окно можно перемещать за заголовок. Изменения сразу видны в игре. Черновик сохраняется в текущем браузере. Набор настроек можно сохранить как JSON и открыть снова через панель. Для выпуска согласованные значения переносятся в `src/settings.js`.

Клавиша **P** открывает окно производительности. Во время движения оно показывает частоту отрисовки глобуса, 95-й перцентиль интервала между кадрами и среднее время работы обработчика кадра на CPU. В окне также видны размер буфера и активный рендерер. Выбор режима меняет только отрисовку, положение глобуса и ход игры сохраняются.

Команда `npm run build` собирает обычную игру в `dist/`. Именно эту папку публикует GitHub Pages.

## Данные карты

Контуры взяты из Natural Earth через [World Atlas 2.0.2](https://github.com/topojson/world-atlas). Группировка суши по материкам основана на [world-countries 5.1.0](https://github.com/mledoze/countries). [Подготовленный файл карты](src/assets/countries.json) доступен под [ODbL 1.0](src/assets/World-Countries-ODbL.txt). Европа и Азия объединены в Евразию. На карте подписаны пять океанов. Лицензии также включены в собранный HTML.

Вершины заранее переводятся в трёхмерные координаты, а длинные дуги один раз разбиваются на короткие отрезки. При вращении и масштабировании используются те же контуры. Берега читаются по краю заливки и тени на воде. Линиями отмечены общие границы стран. Страна при наведении ложится на сферу чуть большего радиуса, а её исходный силуэт вырезается из слоя суши. В покое карта не перерисовывается. Системная настройка уменьшения движения заменяет подъём страны цветовым откликом и сокращает прокрутку после ручного жеста. Короткий тактильный отклик при переходе между странами и выборе доступен на устройствах с поддержкой Web Vibration API.

Камера, жесты, контуры и подписи общие для всех режимов. Рендерер береговой тени пробуется в порядке WebGPU → WebGL 1 → Canvas 2D и переключается на следующий доступный режим при потере контекста. Для сравнения можно открыть `?renderer=webgpu`, `?renderer=webgl` или `?renderer=canvas`. Текущая сборка рассчитана на Safari 15.4+, Chrome 105+ и Firefox 110+.

### Детализация при приближении

`createGlobe` принимает необязательный `tileSource`. Метод `loadTile(tile, { signal })` возвращает GeoJSON с линиями, `null` для пустого тайла или промис с таким результатом. Тайлы `z/x/y` используют градусы долготы и широты с одним тайлом всего мира на уровне 0. Нумерация идёт с запада на восток и с севера на юг. Источник передаёт геометрию в границах тайла, и каждый уровень может отображаться самостоятельно.

Камера выбирает тайлы по их размеру на экране и видимости на сфере. Загруженный родитель виден до готовности всех видимых дочерних тайлов. Настройки источника задают верхние пределы детализации, числа тайлов, размера кэша и одновременных запросов. `maxCameraZoom` позволяет увеличить масштаб камеры с таким источником. При переходе к другой области запросы устаревших тайлов отменяются. Обычная игра использует встроенную карту и работает офлайн.

Методы `projectPoint([longitude, latitude])` и `coordinatesAt({ x, y })` связывают долготу и широту в градусах с координатами в CSS-пикселях относительно холста. За горизонтом и вне диска соответственно они возвращают `null`.
